# MCP Configuration for this Project

## Status: ✅ Configured

The Supabase Model Context Protocol (MCP) has been set up for this project.

## Configuration Location

**Claude Desktop**:
`~/Library/Application Support/Claude/claude_desktop_config.json`

## Current Configuration

```json
{
  "mcpServers": {
    "supabase": {
      "command": "npx",
      "args": ["-y", "@supabase/mcp"]
    }
  }
}
```

## Next Steps

1. **Restart Claude Desktop** to load the MCP configuration
2. **Authenticate** with Supabase when prompted
3. **Select this project** from your Supabase projects list
4. **Configure permissions** (recommended: read-only for development)

## Security Notes

- This MCP configuration uses the remote Supabase MCP server
- Authentication is handled through your Supabase account
- You will be prompted to grant permissions on first use
- See
  [docs/deployment/supabase-mcp-setup.md](docs/deployment/supabase-mcp-setup.md)
  for detailed security guidelines

## Testing the Connection

After restarting Claude Desktop, you can test the connection by asking:

```
Can you see my Supabase database?
```

Or:

```
List the tables in my database
```

## Troubleshooting

If MCP is not working:

1. Verify the config file exists at the location above
2. Restart Claude Desktop completely
3. Check for any authentication prompts
4. Verify you have access to the Supabase project
5. Check Claude Desktop logs for errors

## Additional Configuration

If you need to add more MCP servers or customize the configuration, edit the
`claude_desktop_config.json` file and add additional entries to the `mcpServers`
object.
